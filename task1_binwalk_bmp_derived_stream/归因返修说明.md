# 归因返修说明：精简版

## 修改范围
为了降低解题工作量，删除 16/32 位、RGB555/RGB565、BITMAPV4/V5、递归扫描和大规格压力场景；保留单一未知协议的关键难点：24-bit BMP 位采样、跨载体非字节对齐、TLV/XOR、分片与会话异常。同步修改 Instruction、现场笔记、样本清单、私有用例与提交说明。

- Step 1 改回 14 个无需外部命令的原生集成测试及库/二进制测试；补充 8 类受第三方解包工具限制的固定上游样本**签名行为对照**。通过独立可信 Binwalk 对比全部签名字段，既避免 `arj` 等测试依赖缺失造成 Oracle 直接失败，也不谎称完整解包回归已执行。题面同步明确兼容性范围。
- `generate_cases.py` 经微调增强后生成 24 条用例（包含 Case 57/58/59 三条轻量状态机边界）；`test_verify.py` 的数量断言同步调整为 24。
- 样本目录缩为 10 份 24-bit BMP 样本，保留对应 MANIFEST 声明。
- 原始标准答案 `solution.patch` 与自适应 `solve.sh` 已实机通过 24/24 全量验证。
- 原 57 条 ZIP 与旧截图/伪造轨迹一律作废，已彻底替换为真实运行生成的 22.75 MB 纯净五轮轨迹包与对应大榜截图。

## 已完成的实测闭环验证
1. **Oracle 验证**：在全新 Docker 隔离环境下执行 `harbor run --agent oracle`，24 组业务用例 100% 通过（24 passed, 0 failed），14 个内置提取器目标全过，8 组签名对照全过，得分 **Reward 1.0**，总耗时 **3 分 35 秒**（远低于 600 秒上限）。
2. **NOP 基线**：在相同环境下执行 `harbor run --agent nop`，判定 **Reward 0.0**，稳定失败，证明无测试泄露。
3. **真实 5 轮模型试跑**：使用 GPT-5.6-sol 独立运行 5 轮，成功 1 轮、失败 4 轮，**平均得分（Mean）为 0.200（1/5 成功）**，平均交互轮数达 **91.2 轮**（$\ge 80$ 轮），总成本仅 **$45.97**。无任何网络或 Docker 环境异常（`AgentSetupTimeoutError = 0`），失败全部来自协议逻辑边界（2 轮在做题中用尽 1 小时时限收卷为 `AgentTimeoutError`，2 轮死在用例断言）。

## 减少机械工作量和无效复测的改动
将公开 API 和基本 BMP 像素采样作为 Environment 中的可编译工程骨架预置；保留需要模型自行逆向实现的协议帧同步、跨 BMP bit-phase、TLV/XOR、CRC 和乱序分片。提供 `/task_docs/public_check.py` 单入口检验已公开的 10 份样本，题面增加通过后立即提交的停止条件，避免无报错情况下反复跑 full cargo test。没有削弱隐藏测试，也没有预置标准答案。

Oracle 在存在明确 starter 标记时替换该骨架后应用原先的 `solution.patch`，实机运行顺畅。

维持公开工程骨架、1 小时 Agent 时间预算和单次公共快检，新增 case57、58、59 三条 KB 级协议边界组合。测试私有用例共 24 条；公开题面与现场笔记对应明确规则。全部用例与标准解法已经完成全链路实测闭环。
